One line, at most 160 characters: the excuse an AI agent gives its human for missing a deadline. The program in `main.ts` holds the line, checks it fits the gate (a single line of 1–160 characters), and writes it to `/output/entry.txt` — that text is the whole entry.

## Run it

```sh
node main.ts
```
